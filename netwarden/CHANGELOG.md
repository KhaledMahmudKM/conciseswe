# Changelog

All notable changes are documented here. The format follows Keep a Changelog and the project uses
Semantic Versioning.

## [1.0.0] - 2026-11-17

### Added
* Scan history in SQLite and `netwarden diff` (US-7).
* `--fail-on` exit codes for pipelines (US-8).
* `netwarden demo` practice targets (US-9).
* Container image and CI pipeline.

## [0.2.0] - 2026-10-19

### Added
* Knowledge base matching with CVE, CVSS and remediation (US-4, US-5).
* HTML and JSON reports (US-6).

### Fixed
* ProFTPD versions with letter suffixes, such as 1.3.5a, were compared incorrectly.

## [0.1.0] - 2026-10-05

### Added
* Authorised scope, TCP discovery and banner fingerprinting (US-1 to US-3).
