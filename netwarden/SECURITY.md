# Security policy

## Reporting a vulnerability in NetWarden

Please do not open a public issue. Report it privately through GitHub's "Report a vulnerability"
feature on this repository, with steps to reproduce. You will get an acknowledgement within one week,
and we aim to publish a fix and an advisory within 90 days.

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

## Responsible use

NetWarden must only be used against networks you own or have written permission to assess.
It refuses targets outside the scope file you give it; that check does not replace authorisation.
